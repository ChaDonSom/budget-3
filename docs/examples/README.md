# Vue Component Organization Examples

This directory contains examples demonstrating the before and after states of Vue component organization according to our cleanup standards.

## Examples Included

### 1. Code Organization
- `before/` - Shows current disorganized patterns
- `after/` - Shows standardized organization

### 2. Component Splitting
- `large-component-split/` - Demonstrates how to split a large component

### 3. Folder Structure
- `folder-reorganization.md` - Shows the folder structure changes

## Standards Applied

1. **Script Block Organization**: Consistent ordering of imports, props, composables, etc.
2. **150-line Limit**: Components split when exceeding the limit
3. **Template Organization**: Logical hierarchy and structure
4. **TypeScript**: Proper typing and interfaces
5. **Import Organization**: Grouped and sorted imports
